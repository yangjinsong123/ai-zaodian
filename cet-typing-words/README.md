# cet-typing-words · 边打字边背单词

看中文释义，打出英文单词。打错当场给出正确拼写，同一个词拼错 2 次自动进错词本，可以一键只复习错词。顶部有四六级笔试倒计时和「今日已背」计数。

- 纯前端单页：`index.html` + `style.css` + `app.js` + `words.js`，没有后端、没有依赖、不用构建
- 数据只存在你自己的浏览器（localStorage）：刷新、关掉网页都不会丢，不上传、不用注册登录
- 手机竖屏适配，软键盘弹出时会收紧布局、把输入框留在可视区域

## 怎么用

**直接打开**：下载或 clone 仓库，双击 `index.html` 用浏览器打开就能用（`file://` 也可以，因为词表是 `words.js` 脚本，不需要 fetch）。

**本地起个服务**（手机和电脑在同一个 Wi-Fi 下时，手机也能访问）：

```bash
python3 -m http.server 8000
# 电脑打开 http://127.0.0.1:8000 ；手机打开 http://<电脑局域网IP>:8000
```

**GitHub Pages**：本工具在合集仓库里，页面和样式、脚本都用相对路径（`style.css`、`words.js`、`app.js`），从子路径 `/ai-zaodian/cet-typing-words/` 打开即可：https://yangjinsong123.github.io/ai-zaodian/cet-typing-words/

## 功能和规则

| 功能 | 说明 |
|---|---|
| 看中文打英文 | 显示词性和中文释义，输入框里打英文。打完整个单词自动判对（不用回车）；没打对时按回车 / 点「确认」判错 |
| 拼错提示 | 输入框变红并抖一下，下方显示正确拼写和「这个词第几次拼错」，清空后可以重新打 |
| 错词本 | 同一个词累计拼错 **2 次** 自动进错词本（右上角徽标 +1）；次数跨天累计 |
| 错词复习 | 「错词复习」页点「一键复习」，只刷错词本里的词；打对就移出错词本，打错就排到队尾 |
| 倒计时 | 距离笔试日还有几天（按本机日期计算，每天第一次打开有一个翻牌动画） |
| 今日已背 | 今天在背单词模式里完成的词数，过了零点自动归零 |
| 英式拼写 | 少数词接受英式拼写，比如 neighbour、organise |

想改笔试日期、错几次进错词本，改 `app.js` 顶部的 `EXAM` 和 `WRONG_LIMIT`。

想清空数据：浏览器开发者工具里删掉 localStorage 的 `cet-typing-words:v1`，或者清除该网站数据。

## 词表来源和许可

`words.js` 里的 200 个四级高频词是本项目**自行整理**的：单词按常见四级备考高频词挑选，**中文释义和词性由本项目编写（AI 生成初稿后逐条核对）**，没有复制任何词书、App 或其他开源项目（包括 qwerty-learner）的词库或代码。词表和代码一起以 **MIT 许可** 发布，可以自由使用、修改。

释义只列最常用的一两个意思，不是完整词典；发现错误欢迎提 issue。

## 换成自己的词表

按下面的格式改 `words.js` 就行（`w` 单词，`p` 词性，`m` 释义，`alt` 可选的其他可接受拼写）：

```js
window.WORDS = [
  {"w": "abandon", "p": "v.", "m": "放弃；抛弃"},
  {"w": "neighbor", "p": "n.", "m": "邻居", "alt": ["neighbour"]}
];
```

注意：改了词表后，旧的进度位置可能对不上，可以清空一次数据。
